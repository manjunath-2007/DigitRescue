How It Works

End-to-end architecture matching the training and evaluation notebooks: classical OpenCV preprocessing runs alongside a blind convolutional denoising autoencoder, with a shared CNN classifier evaluating every stage.

System Pipeline

Stage-by-Stage Details

1. MNIST Dataset

Clean 28x28 Reference Digits

The dataset provides 60,000 training images and 10,000 test images of handwritten digits (0–9), normalized from uint8 [0, 255] to float32 [0, 1] with white strokes on a black background. For autoencoder training, the 60,000 training images are split into 54,000 training and 6,000 validation images, leaving all 10,000 test images strictly held out.

2. Noise Generation

Five Synthetic Corruptions

Each clean digit is degraded using five controlled corruptions: Gaussian noise (sigma = 0.4), salt-and-pepper impulse noise (15% pixels), Gaussian blur (sigma = 1.3), spatially varying fading (brightness 0.32–0.48 with smooth Gaussian modulation), and erasure (two 4–6 px zeroed patches placed on foreground strokes).

3. Image Preprocessing

Targeted OpenCV Filters

A classical comparison branch applies a filter chosen by the user: 3x3 Gaussian blur for Gaussian noise, 3x3 median filtering for salt-and-pepper noise, unsharp masking (sigma = 1.0) for blur, and CLAHE (clipLimit = 2.0, 4x4 grid) for fading and erasure. Unknown inputs use mild Gaussian smoothing followed by CLAHE.

4. CNN Recognition

Baseline Classification

The classifier is a convolutional neural network (32 and 64 Conv2D layers with 2x2 max pooling, 128-unit dense layer, 0.3 dropout, and 10-class softmax) trained on clean MNIST digits (99.19% test accuracy). It scores both the raw damaged input and the classically preprocessed output to establish baseline predictions.

5. Denoising Autoencoder

Blind Neural Reconstruction

Receiving only the raw 28x28 damaged image—with no knowledge of the corruption label or classical filter—the Conv2D autoencoder (32→64 encoder with BatchNorm and 2x2 pooling; 64→32→1 decoder with UpSampling2D and sigmoid output, 75,265 parameters) reconstructs clean digit strokes using binary cross-entropy loss.

6. Final Recognition

Restored Digit Classification

The reconstructed 28x28 image is passed into the same CNN classifier to obtain the final digit prediction and top-3 softmax probabilities. On the 10,000 held-out test images, autoencoder restoration raises accuracy from 85.10% to 98.14% on Gaussian noise and from 84.96% to 98.13% on stroke erasure.
