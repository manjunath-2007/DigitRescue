About DigitRescue

DigitRescue is an experimental computer vision system for restoring degraded handwritten digits prior to optical classification.

Problem Statement

Digit classifiers trained on clean scans lose accuracy quickly when inputs suffer from sensor noise, ink fading, motion or focus blur, salt-and-pepper artifacts, or missing stroke segments. Single classical filters help only specific noise types and fail on structural damage such as erased strokes.

Objectives

Build a single blind restoration model that cleans five distinct corruption types without knowing which degradation occurred, compare its visual PSNR and downstream CNN accuracy against targeted OpenCV filters, and expose the workflow through an inspectable web interface.

Methodology

A Conv2D classifier is trained on clean 28x28 MNIST digits. Separately, a symmetric Conv2D denoising autoencoder with BatchNormalization is trained on 270,000 corrupted-to-clean image pairs (54,000 training digits across five corruptions) using a 6,000-image training-set validation split, keeping all 10,000 MNIST test images strictly held out for final evaluation.

Technology Stack

  • Deep Learning: TensorFlow / Keras 2.21 (.keras Conv2D CNN and Autoencoder)
  • Image Processing: OpenCV, NumPy, SciPy
  • Web Backend: Python 3.13, Flask
  • Frontend: HTML5, CSS3, vanilla JavaScript, self-hosted Inter font, local Chart.js

Applications

Pre-cleaning scanned postal codes, archival handwritten ledgers, degraded receipt or check amounts, and low-contrast whiteboard or camera-captured numeric entries before OCR recognition.

Future Scope

Expanding beyond isolated 28x28 single digits to multi-digit sequence segmentation, higher-resolution grayscale documents, and real-world paper texture augmentation during autoencoder training.
